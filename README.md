### Одностраничный сайт прогноз погоды
   
[Прогноз погоды](https://inna-shehovtsova.github.io/JSBasic-homework/?) 
    
1. Сайт показывает погоду в текущем местоположении. 
2. Можно узнать погоду в нужном городе. 
3. Можно опять узнать погоду в нужном городе просто кликнув по истории поиска.

*. Сайт создавался как учебный. Рассчитываю поддерживать его работоспособность до 2025 г. Если что-то пойдет не так, можно писать на innashehovtsova@gmail.com.

### Структура проекта

Ветки вида dev-hw* содержат проект. Число определяет номер версии по возрастающей. Т.е. проследить развитие проекта можно от 1 до 4(сейчас).

В проекте находится модули, разделенные логически:
    1. storeCity - модуль для работы с историей. Там находятся функции запоминания истории, чтения из локального хранилица и отрисовки списка городов на экране.
    2. functions1 - функции приема данных из сервиса   [Open Weather Map API](https://openweathermap.org/current) и отрисовки данных погоды на экране
    3. geoSome - тут находится функция поиска текущего ближайшего города.
